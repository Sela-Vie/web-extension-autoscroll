## SUMMARY
an autoscroll extension for pinterest in the background

## SETUP
how to setup the extension
- go to your browser of choice
- open the `manage extensions` settings page
- turn on `developer mode`
- click `load unpacked`
- select the root directory of you extension(where `manifest.json` is)

## ENABLE/DISABLE
how to enable/disable the extension
<br>
note: reload the page to apply the extension state
- open the `manage extensions` settings page
- turn off/on or on the extension respectively
